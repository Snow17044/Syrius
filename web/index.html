                  Historique

                    Brancher le suivi en direct (une seule fois)
                    1. Touche « Copier la clé » ci-dessous.
                    2. Sur GitHub : ton dépôt Syrius → Settings → Secrets and variables → Actions → New repository secret.
                    3. Nom : SYRIUS_TRAINING_KEY, valeur : colle la clé, puis « Add secret ».

                    Cette clé permet seulement d'envoyer la progression et de lire tes exemples d'entraînement, jamais tes discussions. Pour lancer un entraînement tout de suite : GitHub → Actions → « Entraîner l'IA Syrius » → Run workflow.

                    Pour « Améliorer Syrius », en plus :

                    1. Secret GitHub OPENROUTER_API_KEY : ta clé OpenRouter (la même que dans Vercel).
                    2. GitHub → ton dépôt → Settings → Actions → General → tout en bas, coche « Allow GitHub Actions to create and approve pull requests » → Save.
