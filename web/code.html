Bonjour, je suis Aurora

Code, tableaux de bord, emails pro, sites et sécurité : dis-moi ce qu'il faut faire.

Mes sites

Aurora lit tes sites comme un visiteur et repère les erreurs de sécurité courantes (en-têtes absents, fichiers sensibles exposés, clés secrètes visibles, cookies mal protégés…). Elle n'attaque rien, ne teste aucun mot de passe et ne scanne que les sites dont tu prouves être le propriétaire. Ce n'est pas un test d'intrusion complet.

    Tableaux de bord

    Colle tes chiffres dans la discussion avec Aurora : elle en fait des indicateurs, des graphiques et un tableau. Enregistre ceux que tu veux garder.

      Emails pro

      Aurora trie, résume et prépare des brouillons de réponse. Elle n'envoie jamais rien toute seule : chaque envoi demande ta confirmation. Les emails ne sont plus dans l'application Syrius : ils se gèrent ici, par toi seul.

      Ma boîte mail

      Tri automatique, jour et nuit

      Environ toutes les heures, Aurora lit tes nouveaux emails et les classe. Elle ne déplace, ne supprime et n'envoie rien : ta boîte reste telle quelle. Nova te fait le point au réveil.

      Code

      Aurora écrit, relit et corrige du code. Pour la programmation, elle utilise l'IA spécialisée Codestral quand elle est disponible. Ne colle jamais de mot de passe ni de clé secrète.

      Demander un changement de code

      Une IA programmeuse prépare le changement dans GitHub, lance les tests, puis te propose le résultat. Rien n'est publié sans ton accord. Les parties sécurité (connexion, comptes, filtres, base de données, scanner) lui sont interdites. Tu peux aussi le demander à Aurora dans la discussion.

      Les demandes sont vérifiées toutes les 15 minutes, mais GitHub est parfois en retard (jusqu'à 1 h). Pour démarrer tout de suite : Lancer maintenant (bouton « Run workflow » sur la page GitHub).

        Faire marcher l'IA programmeuse (clés)

        Dans GitHub (Settings → Secrets and variables → Actions), ajoute au moins une clé : CLOUDFLARE_API_KEY + CLOUDFLARE_ACCOUNT_ID (gratuit, environ 120 appels par jour), OPENROUTER_API_KEY (gratuit, 50 appels par jour) ou MISTRAL_API_KEY (la meilleure pour coder). Coche aussi « Allow GitHub Actions to create and approve pull requests » (Settings → Actions → General).

        Conseils pour l'IA programmeuse

        Elle les suit à chaque fois. Quand tu refuses une proposition, ta remarque est ajoutée ici.
