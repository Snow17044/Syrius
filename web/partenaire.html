2. Colle ce code sur ton site

Copie ce code et colle-le dans chaque page de ton site, juste avant la balise </body>.

Garde ce code : il ne sera plus affiché une fois cette page fermée.

Où le coller ?

  • Site fait à la main (HTML) : dans chaque fichier .html, juste avant </body>.
  • WordPress : extension « WPCode » (ou « Insert Headers and Footers ») → Pied de page (footer) → colle le code.
  • Wix : Paramètres → Code personnalisé → Ajouter → « Body – fin » → toutes les pages.
  • Shopify : Thème → Modifier le code → theme.liquid → avant </body>.
  • Squarespace : Paramètres → Avancé → Injection de code → Pied de page.

Personnaliser (facultatif)

Ajoute ces options dans la balise, par exemple data-color="#e67e22" :

  • data-color="#e67e22" : la couleur de la bulle.
  • data-position="left" : la bulle en bas à gauche.
  • data-theme="light" : une fenêtre claire.
  • data-welcome="Bonjour ! Une question ?" : le premier message.
