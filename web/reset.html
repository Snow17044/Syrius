Mot de passe oublié

Entre ton code de secours (celui de la variable SYRIUS_RESET_CODE dans Vercel), puis choisis un nouveau mot de passe. Tous tes appareils seront déconnectés. Les comptes de ta famille ne changent pas.

Réinitialisation désactivée

Pour des raisons de sécurité, cette page ne marche que si tu as ajouté une variable dans Vercel :

  1. Ouvre ton projet Syrius sur vercel.com → Settings → Environment Variables.
  2. Ajoute SYRIUS_RESET_CODE avec un code que tu inventes (12 caractères au moins, par exemple 4 mots au hasard).
  3. Va dans Deployments → ⋯ → Redeploy, attends la fin, puis reviens sur cette page.
