# Néopolis — une civilisation simulée

Ouvre `neopolis.html` dans un navigateur (aucune installation, aucun serveur).

Chaque point sur la carte est une personne avec un âge, un métier, de l'argent,
une santé, une instruction, un couple et des enfants.

## Ce qui est simulé

- **Vie** : naissances, école, rencontres, logement, retraite, maladies, mort, héritage.
- **Économie** : 5 secteurs (agriculture, bois, mines, ateliers, commerce et services).
  Les acheteurs paient le prix affiché, et l'argent revient aux producteurs.
  Les prix montent quand un bien manque et baissent quand il abonde.
  Les gens se tournent peu à peu vers les métiers qui rapportent le plus.
- **État** : impôt, allocation chômage, retraites, aide alimentaire, écoles, hôpitaux,
  recherche, construction de maisons. Il peut s'endetter.
- **Banque centrale** : elle crée de la monnaie quand l'argent manque pour acheter ce qui est produit.
- **Démocratie** : élections tous les 4 ans entre deux partis. Les plus pauvres votent plutôt pour la redistribution,
  les mécontents votent contre le pouvoir en place.
- **Progrès** : l'instruction et la recherche font avancer les techniques,
  qui rendent chacun plus productif (et font baisser la natalité, comme chez nous).
- **Aléas** : sécheresses, épidémies, bonnes récoltes, migrations.
